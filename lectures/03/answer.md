## 宿題

- 取り組んだレベル：基礎
- やったこと：app/agent.py の INSTRUCTIONS と、app/tools.py の make_quiz の docstring をそれぞれ変更し、エージェントのツール選択や回答内容がどのように変化するかを調べた。同じ質問「第2回の内容から確認問題を1問出して」を使用し、変更前後で --trace 付きのコマンドを実行して比較した。
1.INSTRUCTIONS の変更：確認問題を求められた場合、make_quiz ではなくget_lecture_summary を使うように指示を追加した。実行すると、変更前の make_quiz から get_lecture_summary に呼び出されるツールが変わった。
2.docstring の変更：make_quizの説明を、確認問題を出すためには使わないという内容に変更した。関数の処理内容は変更せず、同じ質問を実行した。
- 結果：変更前は make_quizが呼び出され、用語集からランダムに選ばれた用語（SFT）の意味を問う問題が出題された。INSTRUCTIONS変更後は get_lecture_summary が呼び出され、第2回の講義内容をもとにファインチューニングに関する問題が出題された。さらに、docstring変更後も get_lecture_summary が呼び出され、ファインチューニングとLoRAに関する4択問題に変化した。なお、いずれの実行でもツール呼び出し数は1回だった。
- 気づき・疑問：INSTRUCTIONSを変更すると、同じ質問でもエージェントが選択するツールや回答内容が変わることが分かった。また、ツールのdocstringは、各ツールの役割や使用する場面をモデルに伝えるため、ツール選択に影響する可能性があると感じた。今回の docstring の変更実験では get_lecture_summary が選択された。INSTRUCTIONS と docstring の両方が、エージェントのツール選択にどのように影響しているのか、また両者の優先度はどうなっているのか疑問に思った。
